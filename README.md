# CTF writeups site

A plain static site for CTF and lab writeups. No Jekyll, no Ruby, no build step on GitHub's side.
You write Markdown files in `posts/`, and the site turns them into pages in the browser.

## 1. Make it yours

Open `assets/config.js` and change the title, tagline, author name, and links.

## 2. Preview locally

```bash
python3 -m http.server
```

Then open http://localhost:8000. (Opening `index.html` directly won't work, because browsers block `fetch` on `file://`.)

## 3. Put it on GitHub Pages

1. Create a new **public** repo named `<your-username>.github.io`.
2. Upload everything in this folder to it, including the hidden `.nojekyll` file and the `.github` folder. Easiest way:
   ```bash
   git init -b main
   git add .
   git commit -m "Initial site"
   git remote add origin https://github.com/<your-username>/<your-username>.github.io.git
   git push -u origin main
   ```
3. In the repo go to **Settings > Pages**. Under **Build and deployment**, set **Source** to **Deploy from a branch**, pick **main** and **/ (root)**, and save.
4. Wait a minute or two. Your site is at `https://<your-username>.github.io`.

Using a different repo name works too. The site will be at `https://<your-username>.github.io/<repo-name>/`.

## Adding a writeup

```bash
python3 build.py new "Machine name"     # creates posts/YYYY-MM-DD-machine-name.md as a draft
# ...write it, put screenshots in posts/img/...
# change `published: false` to `published: true`
python3 build.py                        # rebuilds posts/index.json
git add . && git commit -m "Add machine-name writeup" && git push
```

`build.py` only needs Python 3, no packages. The included GitHub Action (`.github/workflows/update-index.yml`) also runs it automatically when you push or edit a post on github.com, so you can skip the local step if you prefer. If the Action fails on the first push, check **Settings > Actions > General > Workflow permissions** and choose **Read and write permissions**.

### Front matter

| Field | Example | Notes |
|-------|---------|-------|
| `title` | `"Lame"` | Required |
| `date` | `2026-09-20` | Falls back to the date in the filename |
| `platform` | `Hack The Box` | Becomes a filter |
| `category` | `web` | `web`, `pwn`, `crypto`, `forensics`, `rev`, `osint`, `misc`, `machine`... anything |
| `difficulty` | `easy` | `easy`, `medium`, `hard`, or `insane` (coloured badge) |
| `points` | `100` | Optional |
| `tags` | `[sqli, burp]` | Clickable, filters the home page |
| `summary` | one sentence | Optional; the first paragraph is used if omitted |
| `published` | `false` | Keeps the post out of the site |

### Markdown extras

- Screenshots: `![alt](img/name.png)` with the file in `posts/img/`. Clicking one zooms it.
- Code fences with a language get highlighting and a copy button: ` ```bash `, ` ```python `, ` ```http `, ` ```x86asm `, ` ```powershell `...
- Callouts: start a blockquote with `[!NOTE]`, `[!TIP]`, `[!WARNING]` or `[!FLAG]`.
- Link to another writeup with a relative link: `[earlier post](2026-09-14-other-post.md)`.
- Tables and strikethrough (GitHub-flavoured Markdown) work too.

## Before you publish a writeup

- Hack The Box doesn't allow public writeups for active machines. Wait until the box is retired.
- For live CTFs, wait until the event ends.
- Remove or blur flags if the platform asks, and scrub VPN IPs, cookies, tokens, and personal info from screenshots.

## Troubleshooting

- **Blank list / "Couldn't load posts/index.json"**: run `python3 build.py` and commit `posts/index.json`.
- **A post is missing**: it probably has `published: false`, or you haven't rebuilt the index.
- **404 on GitHub**: repo must be public (on free plans), the branch/folder in Settings > Pages must match, and give it a few minutes after the first push.
- **Old version showing**: hard refresh (`Ctrl`+`Shift`+`R`).

## Layout

```
index.html          page shell
assets/config.js    your title, tagline, links
assets/style.css    styling
assets/app.js       routing, filters, markdown rendering
assets/vendor/      marked, DOMPurify, highlight.js (bundled, no CDN)
assets/fonts/       Newsreader and JetBrains Mono (self-hosted)
posts/*.md          your writeups
posts/img/          screenshots
posts/index.json    generated by build.py
build.py            index builder and `new` command
```
